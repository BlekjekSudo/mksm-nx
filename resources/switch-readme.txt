Shaolin Monks Recomp for Nintendo Switch
NRO author: ArdRecomp
https://github.com/BlekjekSudo/mksm-nx

Copy the switch/ folder to the root of your SD card.
Launch ShaolinMonksRecomp.nro through hbmenu using title takeover for full memory.
The optional MK Shaolin Monk NSP forwards to:
sdmc:/switch/shaolin-recomp/ShaolinMonksRecomp.nro

Game files: switch/shaolin-recomp/game/
Saves and settings: switch/shaolin-recomp/hdd/
Shader cache: switch/shaolin-recomp/cache/
Diagnostics: switch/shaolin-recomp/logs/

When updating, replace only the NRO. Preserve hdd/ and your original game files.
The original game menus control brightness and other gameplay settings.

The repository supplies source and build tools, not the original game.
You must provide your own legally obtained complete Xbox game files.
A locally generated SD setup contains your private game files. Do not redistribute it.
The project license does not license the original game's code, names, or artwork.
